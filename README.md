# 힘 단위 변환기

`force_converter - GUI수정.py`는 입력한 힘(force) 값을 서로 다른 단위로 변환해 보여주는 Tkinter 기반 GUI 프로그램입니다.

## 프로그램 용도

다음 세 단위 사이의 힘 값을 변환합니다.

- `N` (뉴턴)
- `kgf` (킬로그램힘)
- `kN` (킬로뉴턴)

입력 단위를 선택하고 값을 입력한 뒤 **변환** 버튼을 누르면, 선택한 단위를 제외한 나머지 두 단위의 변환 결과가 표시됩니다. 변환에는 다음 기준이 사용됩니다.

- `1 kgf = 9.81 N`
- `1 kN = 1000 N`

화면의 **초기화** 버튼은 입력값과 결과를 지우고 입력란에 포커스를 돌려놓습니다. **종료** 버튼은 프로그램을 종료합니다. 키보드의 `Enter` 키로도 변환할 수 있습니다.

## 실행 명령

PowerShell 또는 명령 프롬프트에서 Python 파일이 있는 폴더로 이동한 후 실행합니다.

```powershell
cd "C:\Python\week4"
python ".\force_converter - GUI수정.py"
```

Python 실행 명령이 `py`로 설정된 환경에서는 다음과 같이 실행할 수 있습니다.

```powershell
cd "C:\Python\week4"
py ".\force_converter - GUI수정.py"
```

## 필요한 환경

- Python 3.9 이상
  - 코드에서 `dict[str, float]` 형식의 타입 표기를 사용하므로 Python 3.9 이상이 필요합니다.
- Python 표준 GUI 라이브러리인 Tkinter
  - 프로그램은 `tkinter`, `tkinter.ttk`, `tkinter.messagebox`를 사용합니다.
- `force_converter - GUI수정.py`는 별도의 외부 Python 패키지를 사용하지 않습니다.
- `load_analyzer.py`는 응력 그래프 저장을 위해 외부 패키지 `matplotlib`가 필요합니다.
- GUI를 표시할 수 있는 데스크톱 환경이 필요합니다.

## 정상 입력 예시

아래 예시는 입력란에 값을 넣고 해당 입력 단위를 선택한 뒤 **변환**을 누르는 경우입니다.

| 입력값 | 입력 단위 | 표시되는 변환 결과 |
|---:|:---:|:---|
| `10` | `N` | `0.00 kN`, `약 1.02 kgf` |
| `9.81` | `N` | `0.01 kN`, `약 1.00 kgf` |
| `1` | `kgf` | `9.81 N`, `0.01 kN` |

| `-3` | `kN` | `-3000.00 N`, `약 -305.81 kgf` |

소수와 음수는 유한한 숫자로 해석되면 입력할 수 있습니다. 결과는 소수 둘째 자리까지 표시됩니다. `kgf` 결과에는 화면 표시상 `약`이 붙습니다.

## CSV 하중 분석기

`load_analyzer.py`는 하중 측정 CSV를 읽어 응력을 계산하고, 결과 CSV와 시간-응력 그래프를 저장하는 프로그램입니다. 기본 입력 파일은 `load_bad.csv`이며, 명령줄에서 다른 CSV 파일을 지정할 수 있습니다.

### 계산 및 출력

- 단면적은 코드의 `AREA_MM2 = 100.0`으로 설정되어 있으며 단위는 `mm²`입니다.
- 응력은 `force_N / AREA_MM2`로 계산되며 결과 단위는 `MPa`입니다.
- 기준 응력은 `6 MPa`이며, 이를 초과하는 유효 데이터 개수를 출력합니다.
- 데이터 개수, 최대 하중과 시간, 최대 응력과 시간, 기준 응력 초과 데이터 개수를 출력합니다.
- 그래프의 x축은 `Time (s)`, y축은 `Stress (MPa)`이며 각 점을 선으로 연결합니다. 최대 응력 점은 강조 표시되고 값이 그래프에 표시됩니다.

### 출력 파일

분석이 완료되면 프로그램 파일과 같은 폴더에 다음 파일을 저장합니다.

- `load_result.csv`: 유효한 행의 `time_s`, `force_N`, `stress_MPa` 데이터
- `stress_plot.png`: 시간-응력 그래프

입력 CSV는 읽기만 하며 덮어쓰지 않습니다.

### 오류 처리 규칙

- CSV 열 이름이 `time_s`, `force_N`과 정확히 일치하지 않으면 오류로 처리합니다.
- `time_s` 또는 `force_N`이 빈칸, 숫자가 아닌 값, `NaN` 또는 무한대이면 해당 행을 제외합니다.
- 제외한 행마다 원본 CSV의 행 번호, 문제가 있는 열 이름, 문제 값을 출력합니다.
- 제외한 행은 응력 계산, 결과 CSV, 그래프에서 모두 제외합니다.
- 제외한 행 수와 유효한 데이터 수를 출력합니다.
- 유효한 데이터가 하나도 없으면 계산과 그래프 생성을 중단하고 안내 메시지만 출력합니다.

### CSV 열 이름과 데이터

상단의 **CSV 찾아보기** 버튼으로 분석할 CSV를 선택합니다. CSV의 첫 번째 행에는
다음 두 열이 정확히 있어야 합니다.

| 열 이름 | 의미 | 단위 |
|:---|:---|:---:|
| `time_s` | 측정 시간 | `s` |
| `force_N` | 하중 | `N` |

선택한 파일의 경로는 읽기 전용 칸에 표시되고, 유효한 데이터 행 수가 갱신됩니다.
응력은 `force_N / A`로 계산되며 결과 단위는 `MPa`입니다. 단면적의 단위가
`mm²`이면 `N/mm² = MPa`이므로 별도 단위 변환이 필요하지 않습니다.

단면 종류로 사각형, 원형봉, 원형관, 사각형관, H형강을 선택할 수 있습니다.
선택한 단면에 필요한 치수 입력칸만 표시됩니다. 모든 치수는 `mm`, 단면적은
`mm²`로 통일합니다.

| 단면 종류 | 입력 치수(mm) | 단면적 계산식 |
|:---|:---|:---|
| 사각형 | 폭 `b`, 높이 `h` | `A = b × h` |
| 원형봉 | 외경 `D` | `A = πD² / 4` |
| 원형관 | 외경 `D`, 내경 `d` | `A = π(D² - d²) / 4` |
| 사각형관 | 외부 폭 `B`, 외부 높이 `H`, 내부 폭 `b`, 내부 높이 `h` | `A = BH - bh` |
| H형강 | 전체 폭 `B`, 전체 높이 `H`, 플랜지 두께 `tf`, 웨브 두께 `tw` | `A = 2Btf + (H - 2tf)tw` |

**분석**을 누르면 단면적이 계산되고, 최대 응력과 해당 시간이 표시됩니다. 하단
그래프는 `Time (s)`-`Stress (MPa)` 그래프로 갱신됩니다.

### 이상화 단면 가정

- 모든 단면은 균일한 단면적을 가진 이상화된 단면으로 취급합니다.
- 하중은 단면에 수직으로 균일하게 작용한다고 가정하며, 응력은 평균 정상응력
  `σ = F / A`만 계산합니다.
- 굽힘, 전단, 좌굴, 응력 집중, 필렛, 모따기, 용접부, 국부 좌굴 및 재료의
  비선형 거동은 고려하지 않습니다.
- 원형관과 사각형관은 외부 단면에서 내부 빈 공간을 뺀 단순 중공 단면으로
  취급합니다.
- H형강은 플랜지 두 개와 웨브 하나가 직사각형으로 연결된 단순 단면으로
  취급하며, 겹치는 부분은 다음 식에 따라 계산합니다.
  `A = 2Btf + (H - 2tf)tw`

새 CSV를 선택하면 이전 단면적과 응력 결과가 지워지고 다시 분석해야 합니다.
단면 종류나 치수를 변경해도 기존 결과가 무효화되며
`조건 변경됨: 다시 분석필요`가 표시됩니다. 입력 오류가 발생한 경우에도 이전
분석 결과를 유지하지 않으며, 유효한 값을 입력하고 **분석**을 다시 누르면 수치와
그래프가 갱신됩니다.

선택한 CSV에 유효한 데이터가 하나도 없으면 분석을 중단하고 안내 창을 표시합니다.
필수 열이 없거나 열 이름이 정확하지 않은 경우에는 다음 열 이름이 필요하다는
안내를 표시합니다.

```text
time_s (시간, s)
force_N (하중, N)
```

치수는 다음 조건을 만족해야 합니다.

| 단면 | 유효 치수 조건 |
|:---|:---|:---|
| 사각형 | `b > 0`, `h > 0` |
| 원형봉 | `D > 0` |
| 원형관 | `D > d > 0` |
| 사각형관 | `B > b > 0`, `H > h > 0` |
| H형강 | `B > tw > 0`, `H > 2tf > 0` |

### 오류 처리 규칙

- 필수 열이 없거나 열 이름이 정확하지 않으면 필요한 열 이름
  `time_s`, `force_N`을 안내하고 분석하지 않습니다.
- `time_s` 또는 `force_N`이 빈칸, 숫자가 아닌 값, `NaN`, 무한대이면 해당 행을
  제외하고 유효 데이터 수를 표시합니다.
- 유효 데이터가 하나도 없으면 분석을 중단하고 안내합니다.
- 단면 치수가 숫자가 아니거나 빈칸이면 올바른 값을 입력하라는 안내를 표시합니다.
- 단면 치수가 `0`, 음수 또는 단면별 관계 조건을 만족하지 않으면 해당 조건을
  안내하고 분석하지 않습니다.
- 새 CSV를 선택하거나 단면 종류·치수를 변경하면 이전 단면적과 응력 결과를
  무효화하고 `조건 변경됨: 다시 분석필요` 상태를 표시합니다.
- 입력 오류가 발생해도 이전 분석 결과를 현재 결과처럼 유지하지 않습니다.
- 유효한 치수로 **분석**을 다시 실행하면 단면적, 최대 응력, 최대 응력 시간 및
  그래프를 새 결과로 갱신합니다.
