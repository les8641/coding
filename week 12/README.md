# Week 12 풍속 분류 실습

이 폴더는 다음 1시간 풍속이 강풍 기준인 4.0 m/s 이상인지 분류하고,
12월 평가 기간의 여러 분류 방법을 비교하는 실습 코드와 결과를 담습니다.

모든 시각은 KST 기준으로 처리하며, `prediction_time`과 `target_time`은
정확히 1시간 차이여야 합니다.

## 파일 구성

- `wind_dataset.csv`: 원본 풍속 데이터
- `classify_wind.py`: 라벨 생성, 학습/평가 분할, 로지스틱 회귀 학습 및 결과 계산
- `classified_wind.csv`: 원본 행에 `wind_next1h` 라벨을 추가한 전체 데이터
- `classification_predictions.csv`: 12월 평가 행의 실제값과 각 방법의 예측 결과
- `classification_scores.csv`: 평가 방법별 혼동행렬과 분류 지표
- `plot_strong_wind_december.py`: 12월 1~7일 실제 풍속 및 강풍 예측 그래프 생성
- `strong_wind_december.png`: 위 그래프의 결과 이미지

## 데이터 분할

- 학습 기간: 정답 시각 기준 2023년 1월 1일부터 2024년 11월 30일까지
- 평가 기간: 정답 시각 기준 2024년 12월 1일부터 2024년 12월 31일까지
- 전체 행 수: 17,464행
- 학습 행 수: 16,720행
- 평가 행 수: 744행

실제 풍속이 4.0 m/s 이상이면 정답 라벨을 `1`, 아니면 `0`으로 설정합니다.

## 분류 방법

`classify_wind.py`는 다음 세 가지 기준 예측과 로지스틱 회귀를 비교합니다.

1. 항상 0 예측
2. 현재 풍속이 4.0 m/s 이상이면 1 예측
3. 로지스틱 회귀
   - 입력: 현재 풍속, 기온, 습도, 1시간 전 풍속, 2시간 전 풍속
   - 표준화는 학습 행으로만 계산합니다.
   - 학습 행으로만 로지스틱 회귀를 학습합니다.
   - 클래스 가중치는 사용하지 않습니다.
   - 강풍 확률 임계값 0.50 판정과 0.20 판정을 모두 제공합니다.

실제 강풍 기준은 항상 `target_wind_speed_ms >= 4.0 m/s`로 유지합니다.

## 평가 결과

평가 행은 744행이며 실제 강풍은 39행입니다.

| 방법 | 적중 | 놓침 | 오경보 | 정상 판정 | 정확도 | 정밀도 | 재현율 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 항상 0 | 0 | 39 | 0 | 705 | 0.9475806452 | 해당없음 | 0.0000000000 |
| 현재 풍속 4.0 이상 | 9 | 30 | 30 | 675 | 0.9193548387 | 0.2307692308 | 0.2307692308 |
| 로지스틱 회귀 0.50 | 4 | 35 | 6 | 699 | 0.9448924731 | 0.4000000000 | 0.1025641026 |
| 로지스틱 회귀 0.20 | 15 | 24 | 41 | 664 | 0.9126344086 | 0.2678571429 | 0.3846153846 |

용어의 의미는 다음과 같습니다.

- 적중: 실제 강풍을 강풍으로 예측
- 놓침: 실제 강풍을 비강풍으로 예측
- 오경보: 실제 비강풍을 강풍으로 예측
- 정상 판정: 실제 비강풍을 비강풍으로 예측

## 실행 방법

분류 및 평가를 실행합니다.

```powershell
cd "C:\Python\week 12"
python .\classify_wind.py
```

실행하면 `classified_wind.csv`, `classification_predictions.csv`,
`classification_scores.csv`가 다시 생성됩니다.

12월 1~7일 그래프를 생성합니다.

```powershell
python .\plot_strong_wind_december.py
```

실행하면 `strong_wind_december.png`가 생성되고, 12월 2일의
첫 번째 틀린 사례도 콘솔에 출력됩니다.

## 그래프 내용

`strong_wind_december.png`는 두 그래프를 포함합니다.

- 위쪽: 정답 시각별 실제 풍속과 4.0 m/s 기준선
- 아래쪽: 정답 시각별 실제 강풍과 0.50·0.20 로지스틱 판정
- 두 그래프는 같은 정답 시각 가로축을 사용합니다.

아래쪽 그래프의 시각별 점은 해당 시각에서의 강풍 판정을 표시합니다.

## 12월 2일 틀린 사례

12월 2일에서 발견된 첫 번째 틀린 사례는 다음과 같습니다.

```text
실제 풍속: 4.0 m/s
실제 강풍: 1
0.50 예측: 0
0.20 예측: 0
강풍 확률: 0.0228080770
```

실제 풍속은 정확히 4.0 m/s이지만, 두 로지스틱 임계값 모두 강풍으로 판정하지
못한 놓침 사례입니다.
