# ASOS 풍속 예측 실험

2026-11-11에 수행한 ASOS 108번 관측소 풍속 예측 작업입니다.

## 데이터 준비

- 원본: `asos_108_2023_2024.csv`
- 관측 시각을 1시간 간격으로 재구성했습니다.
- 누락 시각은 빈 행으로 간주하고, 입력 또는 정답이 비어 있는 행은 학습 데이터에서 제외했습니다.
- 입력 변수 5개:
  - 현재 풍속
  - 1시간 전 풍속
  - 2시간 전 풍속
  - 현재 기온
  - 현재 습도
- 정답: 정확히 1시간 뒤 실제 풍속
- `prediction_time`과 `target_time`은 KST입니다.

## 학습 및 평가

- 학습 기간: 정답 시각 2023-01-01 ~ 2024-11-30
- 평가 기간: 정답 시각 2024-12-01 00:00 ~ 2024-12-31 23:00
- 시간순으로 자료를 나누었으며, 평가 중 재학습하지 않았습니다.
- 선형회귀와 랜덤포레스트를 비교했습니다.
- 음수 예측은 0으로 치환했습니다.

랜덤포레스트 설정:

- `n_estimators=100`
- `max_depth=6`
- `min_samples_leaf=5`
- `random_state=42`

## 실행

```powershell
python train_wind_model.py
python plot_prediction_week.py
```

`train_wind_model.py`는 `predictions.csv`를 생성하고 12월 전체 MAE를 출력합니다.
`plot_prediction_week.py`는 2024-12-01 00:00부터 2024-12-07 23:00까지의
실제값, 현재 풍속 유지 기준 예측, 선형회귀 예측을 `prediction_week.png`로 저장합니다.

## 결과

학습 행수는 16,720행, 평가 행수는 744행입니다.

| 방법 | 12월 MAE (m/s) |
|---|---:|
| 현재 풍속 유지 | 0.6534946237 |
| 선형회귀 | 0.5945766854 |
| 랜덤포레스트 | 0.5938072290 |

랜덤포레스트는 선형회귀보다 MAE가 0.0007694564 m/s 낮고,
현재 풍속 유지 기준보다 0.0596873946 m/s 낮았습니다.
